# 0007. deploy in kubernetes

* **Data:** 2025-07-05
* **Status:** Suggested
* **Author:**  Dmitry Stelmakh <TG: @StelmakhDigital>

## Description
Необходимость оркестрации 5+ микросервисов с возможностью быстрого горизонтального масштабирования

## Solution
В качестве решения предлагаю Kubernetes (есть Swarm от Docker, но на него нет стольких интеграций и функциональных возможностей). При правильной конфигурации, поды Kubernetes в фоновом режиме будут скейлиться самостоятельно под необходимую нагрузку.

## Consequences
Из плюсов:
    - Автомасштабирование по CPU/RAM
    - liveness \ readiness пробы - и политика перезапуска (повышает доступность сервиса)
Из минусов:
    - Сложность конфигурирования
