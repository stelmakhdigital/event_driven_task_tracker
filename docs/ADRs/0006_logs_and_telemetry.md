# 0006. logs and telemetry

* **Data:** 2025-07-05
* **Status:** Suggested
* **Author:**  Dmitry Stelmakh <TG: @StelmakhDigital>

## Description
Если все же инцидент достиг свое критического значения, то важно найти его эпицентр - в этом поспособствуют логи и телеметрия запроса.

## Solution
Для телеметрии запроса использовать Jaeger. Для анализа ошибок и стектрейсов - Sentry. Дополнительно настроить хранение и ротацию логов у подов в кубере. 

## Consequences
Из плюсов:
    - Sentry автоматически перехватывает исключения вместе с контекстом пользовательского запроса
    - у Jaeger и Sentry отличная поддержка python и FastAPI
    - Jaeger визуализирует распределённые транзакции между микросервисами

Из минусов:
    - Sentry не поможет в анализе Kafka-событий
    - Jaeger сложен в настройке гарантированной доставки сообщений
    - Дублирование логов из-за сложности сервисов (сложности в настройки синхронизаций)
