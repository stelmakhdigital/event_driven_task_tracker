# 0001. FastApi main framework

* **Data:** 2025-07-05
* **Status:** Suggested
* **Author:**  Dmitry Stelmakh <TG: @StelmakhDigital>

## Description
Выбор основного фреймворка для микросервисов (в частности для `Task Service`, `API Gateway` и других сервисов) для снижения временных издержек в разработке и поддержке микросервисов

## Solution
FastApi - один из быстрых асинхронных фреймворков на Python c хорошей документацией (в том числе и Starlette). С поддержкой pydantic (для валидации \ сериализации) из коробки. Так же есть встроенный запуск синхронного кода (если например вызывается сторонняя синхронная библиотека) в отдельном потоке.

## Consequences
Из плюсов: pydantic, обширное комьюнити, экономие времени при разработке и поддержке

Из минусов: 
    - все еще не стабильный билд (v.0.115+) и можно проблемы с производительностью в новых версиях
    - асинхронность работает на надстройке AnyIO - с одной стороны обертка позволяет запускать как и с asyncio так и c trio и позволяет иногда не задумываться о процессах и потоках для "параллельной обработки", но с другой стороны рождает некую избыточность
