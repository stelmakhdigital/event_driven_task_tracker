# 0003. Sharding in Postgres

* **Data:** 2025-07-05
* **Status:** Suggested
* **Author:**  Dmitry Stelmakh <TG: @StelmakhDigital>

## Description
Со временем работа сервиса приведет к "разбуханию" основной таблицы с задачами (>2-3 Млн. задач в месяц)

## Solution
Шардирование через citus. Позволит снизить общую нагрузку на таблицу. 

## Consequences
Из плюсов:
    - более быстрое получение данных (при условии правльности индексов и шардов по диапозону)
Из минусов:
    - нельзя использовать JOIN у шардов
    - "танцы с бубном" при миграции
