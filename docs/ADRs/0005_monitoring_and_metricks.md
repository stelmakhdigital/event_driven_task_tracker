# 0005. Monitoring and metricks

* **Data:** 2025-07-05
* **Status:** Suggested
* **Author:**  Dmitry Stelmakh <TG: @StelmakhDigital>

## Description
В highload важно не допускать проблем с сервисами и разбираться с инцидентами еще до наступления критических ситуаций. Мониторинг разнообразных метрик "жизни" сервисов как раз в этом помогает. 

## Solution
Мониторинг на основе связки Prometheus (метрики) и Grafana (дашборд)

## Consequences
Из плюсов:
    - Интеграция с кубером (если планируется развертывание микросервисов в кубере)
    - возможность удобной настройки для alert-оповещений
Из минусов:
    - требуется настройка для каждого из микросервиса
