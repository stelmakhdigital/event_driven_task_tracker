# 0004. Cache in redis

* **Data:** 2025-07-05
* **Status:** Suggested
* **Author:**  Dmitry Stelmakh <TG: @StelmakhDigital>

## Description
Даже с использованием шардов в БД нагрузка на нее все еще высокая. Можно использовать кеш чтобы убрать с БД "мусорные однотипные запросы" (частые запросы на получение информации > 5 RPS (например по методам  `GET /tasks/{id}`))

## Solution
В качестве решения - Redis Cluster с TTL в 5 мин. 

## Consequences
Из плюсов:
    - в более чем в половина, снизим назрузку на БД
    - есть откат кеша при изменении задач
Из минусов:
    - нужно будет настраивать синхронизацию кеша между шардами
